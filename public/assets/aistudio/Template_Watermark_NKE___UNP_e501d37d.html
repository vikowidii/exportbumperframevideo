Watermark pojok kanan atas dengan dua logo, frame biru–oranye, dan latar slate. Semuanya vektor, jadi tetap tajam di HD maupun 4K. Pakai halaman ini sebagai dasar slide atau overlay video.

Cara memakai

  1. Pilih latar dan tata letak di atas untuk melihat hasilnya.
  2. Untuk video: buka file watermark-NKE-UNP-(nama gaya).svg di Inkscape, Illustrator, atau Figma, lalu ekspor PNG transparan 1920 px atau 3840 px.
  3. Taruh PNG itu di layer paling atas di CapCut, Premiere, atau DaVinci, rapat ke pojok kanan atas.
  4. Untuk slide: salin kode SVG lalu tempel di master slide, atau pakai halaman ini sebagai dasar HTML.
  5. Logo UNP digambar ulang sebagai vektor sederhana. Jika ada file logo resmi, ganti bagian grup UNP di SVG dengan file tersebut.
